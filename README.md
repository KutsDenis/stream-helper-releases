# Stream Helper

<img src="icon.png" width="80" alt="Stream Helper">

Приложение для чата TikTok LIVE с оверлеем на мониторе и в VR, озвучкой сообщений и звуками событий.

## Скачать и установить

[Скачать установщик Stream Helper 0.2.1 для Windows x64](https://github.com/KutsDenis/stream-helper-releases/releases/download/v0.2.1/StreamHelperApp-win-Setup.exe)

1. Скачайте и запустите установщик.
2. Откройте Stream Helper, укажите имя канала TikTok и подключитесь к эфиру.
3. Настройте озвучку и оформление в приложении.

Устанавливать npm, Node.js или .NET вручную не нужно. Если WebView2 отсутствует, установщик добавит его автоматически; для загрузки нужен интернет. При выборе VR приложение предложит скачать и установить необходимый VR-компонент, если его нет. Windows может запросить права администратора.

## Возможности

- Чат, подарки, подписки, репосты, количество зрителей и лайков.
- Оверлей на мониторе с перемещением, изменением размера и пропуском кликов в игру.
- VR-панель с настройкой положения, поворотов, размера и кнопки центровки.
- Озвучка сообщений голосами Windows и отдельные звуки событий.
- Пауза озвучки назначенной клавишей или кнопкой руля.
- Настройка интервала после завершения озвучки каждого сообщения.
- Информер трансляции для захвата окном или добавления по адресу, с настройкой цветов и размера текста.
- Уровни звуков подарков по накопленным монетам каждого зрителя.
- Выбор сохранения сумм между запусками и ручной сброс сессии.
- Проверка обновлений в приложении.
