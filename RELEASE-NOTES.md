# Stream Helper 0.1.0

Первый публичный релиз.

- Чат TikTok LIVE с отображением сообщений, подарков, подписок, репостов, зрителей и лайков.
- Оверлей на мониторе или в VR. Настройка оформления, размера и положения.
- Озвучка чата голосами Windows и отдельные звуки событий.
- Уровни звуков подарков по накопленным монетам каждого зрителя, с выбором сохранения сумм между запусками.
- Установщик Windows и поддержка обновлений через GitHub Releases.

- Автоматическая подготовка VR: скачивание и установка необходимого компонента из приложения с подтверждением пользователя.
