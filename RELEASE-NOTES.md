# Stream Helper 0.2.1

- Исправлена очередь озвучки: сообщение появляется в чате, когда начинается его чтение; пауза удерживает следующие сообщения и оставшееся время интервала.
- Звуки событий воспроизводятся сразу и не ждут очередь озвучки.
- Добавлено отдельное демо только с текстовыми сообщениями для проверки очереди.
- Добавлено ненавязчивое уведомление о новой версии при запуске. Установка закрывает приложение, обновляет его и запускает снова без дополнительного окна с кнопкой подтверждения.
