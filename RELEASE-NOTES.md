# Stream Helper 0.2.0

- Добавлена пауза озвучки чата назначенной клавишей или кнопкой руля.
- Добавлена настройка интервала между озвучиваемыми сообщениями: от 0 до 5 секунд.
- Добавлен отключённый по умолчанию информер трансляции. Его можно вывести отдельным окном или добавить по адресу.
- Добавлены настройки цветов, непрозрачности фона и размера текста информера.
- Обновлены установщик и система обновлений для Windows.
